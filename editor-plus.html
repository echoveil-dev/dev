Editor Plus Beta

Colors, icons, tabs, favorites and navigation for the Unity Editor's Hierarchy and Project windows, in one package.

Beta, version 0.8.5. Developed and tested on Unity 6000.2. It also compiles cleanly on 6000.4 and 6000.6, but has not been run through a full test there yet. Editor-only: nothing from the package is included in your builds.

What it does

Colors and icons

Alt+click a Hierarchy row or a Project folder (or right-click, then Editor Plus > Color and Icon...) to open a palette. Pick a color, a built-in icon, or search the icons of Unity's own component and asset types. A color tints the row or folder; an icon replaces the object's icon, or sits as a badge on a folder.

Folder tabs

Middle-click a folder to open it as a tab in the Project window's toolbar. Tabs can hold folders, assets and scene objects, and show their color and icon. Click a tab to jump to it.

Favorites with pages

Hold Alt over the Project window, or start a drag with Alt held, and a favorites panel opens over the folder tree. Drop folders, assets or GameObjects on it. Favorites live on named pages you can add, rename and switch between.

Selection history and bookmarks

A bar above the Inspector gives you back and forward through what you have selected, a history menu, and bookmarks you can pin for quick access.

Zebra rows and tree lines

Alternating row stripes and parent-to-child lines in the Hierarchy and the Project folder tree. Both can be switched off.

Requirements and limitations

  • Unity 6 (6000.2 or newer).
  • Windows is the main platform. macOS and Linux have not been tested.
  • The Project window features (tabs, favorites, folder navigation) work by reaching into the layout of Unity's built-in windows. A Unity update can change that layout, so those features may need an update after a new Unity release.
  • Objects in an unsaved scene can't be decorated; save the scene first.
