Editor Plus: user guide

Quality-of-life additions for the Unity Editor. Editor-only: nothing from this package ends up in your builds.

Requirements

  • Unity 6 (6000.2 or newer). Developed and verified on 6000.2.8f1.
  • Windows is the primary platform. macOS and Linux are untested.

Installing

Package Manager > + > Add package from git URL, Add package from tarball, or Add package from disk (pick package.json). You can also copy the package folder into your project's Packages/ folder.

Features

Colors and icons (Hierarchy and Project window)

  • Alt+click a Hierarchy row or a folder in the Project window (a quick click, no drag), or right-click it > Editor Plus > Color and Icon...
  • Pick a color, a built-in icon, or any component/asset type icon (use the search box in the palette).
  • In the Hierarchy a color tints the row and an icon replaces the object's icon.
  • On a folder a color tints the folder and an icon is drawn as a badge in its bottom-right corner. Minimal folder icons (gear menu or Preferences) draws the icon in place of the folder instead.
  • Use No color / No icon in the palette to go back to the default.

Objects in an unsaved scene can't be decorated; save the scene first.

Tabs (Project window toolbar)

Tabs sit in the Project window's toolbar, between the create "+" menu and the search field.

  • Middle-click a folder to open it as a tab.
  • The strip's + button adds the selected item, or the folder being shown if nothing is selected.
  • You can also drop folders, assets or GameObjects on the strip, or right-click an item > Editor Plus > Open in New Tab.
  • Click a tab to select it (folders navigate the folder tree). Middle-click or the x closes it. Right-click a tab for Close other tabs / Close all tabs.
  • Tabs show the item's color and icon.

Favorites (Project window)

  • Hold Alt for a moment over the Project window, or start a drag with Alt held: a favorites panel covers the folder tree.
  • Drop folders, assets or GameObjects on it to add them. Click an item to open it (folders are navigated in the tree). Right-click an item or click x to remove it.
  • The pager at the bottom (< Page 1 >) switches pages. Click the page name to rename it, + adds a page, right-click the name to delete a page.
  • You can also right-click an asset > Editor Plus > Add to Favorites.

A quick Alt+click opens the color/icon palette instead; the panel only appears when Alt is held or a drag is under way.

Inspector bar

  • Back / forward through your selection history, and a History menu of recent selections.
  • The star bookmarks the current selection. Bookmarks appear as chips in the bar; right-click a chip to remove it.

Zebra rows and tree lines

Alternating row stripes and parent-to-child lines in the Hierarchy and in the Project folder tree.

Settings

Use the gear button in the tab strip, Edit > Preferences > Editor Plus, or Tools > Editor Plus:

SettingDefault
Zebra rowson
Parent-to-child lineson
Minimal folder icons (icon replaces the folder instead of a badge)off

These are saved per user.

Where your data is saved

Colors, icons, bookmarks, tabs and favorites are stored in ProjectSettings/EditorPlus.asset. Commit that file to share them with your team; delete it to reset everything. Selection history is kept for the editor session only.

Troubleshooting

  • The tab strip overlaps Unity's buttons. The strip is placed over the empty part of the Project toolbar. In an unusually narrow window it can collide with the search field; widen the window.
  • A bar or the favorites panel doesn't appear. It depends on Unity's internal window layout, which can change between Unity versions. Run Tools > Editor Plus > Debug > Dump Window Trees and include the console output when reporting the problem.
  • Folders open in the wrong place from a tab or favorite. This uses an internal Unity method; if Unity changes it, a warning is logged once and the item is selected instead.

To report a problem, see Support.

Uninstalling

Remove the package in Package Manager. You can then delete ProjectSettings/EditorPlus.asset.
