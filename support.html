Reporting a problem

These details make a problem much quicker to track down:

  1. Your Unity version, e.g. 6000.2.8f1 (Help > About Unity).
  2. The Editor Plus version (shown in Package Manager).
  3. Your operating system.
  4. What you did, what you expected, and what happened.
  5. Any red or yellow messages in the Console, copied as text.
  6. If a bar, tab strip or panel is missing or in the wrong place: run Tools > Editor Plus > Debug > Dump Window Trees and include what it writes to the Console.

Common questions

The tab strip overlaps a Unity button

The strip sits in the empty part of the Project window's toolbar. In a very narrow window it can run into the search field. Widen the window.

A tab or favorite selects a folder but doesn't open it in the tree

Opening a folder in the tree uses a method inside Unity that can change between versions. If Unity changes it, a warning appears once in the Console and the item is selected instead. Please report it with your Unity version.

My colors, tabs and favorites are gone

They are stored in ProjectSettings/EditorPlus.asset inside your project. Check that the file is still there and that it was committed if you share the project.

Uninstalling

Remove the package in Package Manager. You can then delete ProjectSettings/EditorPlus.asset.

More detail is in the user guide.
